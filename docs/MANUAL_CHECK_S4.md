# FileTmpShelf 发布前手动验收清单（终版）

> 发布 Gate 的强制人工验收。覆盖 S4 面板拖放 / S2 拖出移动 / S3 全局热键 / S1 存储恢复 /
> 设置窗口 / 图标 / dmg 安装后干净环境验收。
>
> 环境：**M 系 Mac，macOS 13+**（建议同时抽验 14/15），非沙盒构建。
> 验收人逐项打勾；任何 ☐ 不通过均记录为 P0/P1 缺陷，修复后复验。

## 0. 准备

- [ ] `cd FileTmpShelf && xcodebuild -project FileTmpShelf.xcodeproj -scheme FileTmpShelf -destination "platform=macOS" -derivedDataPath build/DerivedData build` 成功
- [ ] `xcodebuild test` 全绿（0 失败；HotKeyManagerTests 注册 ⌥C，先确认无其他 xcodebuild 进程占用）
- [ ] 运行 app，⌥C 唤出面板（或点菜单栏图标），面板出现在主屏右上角
- [ ] 在 Finder 准备测试素材：2 个文本文件、1 个文件夹、1 个大文件（≥1GB，稀疏文件即可）
- [ ] 打开一个「前台对照应用」（推荐 TextEdit 光标置于文本内，确保它持有键盘焦点）

## 1. S4 面板拖放 — 拖入不激活、不打断前台应用（重点验收项）

对应 SPIKE §6.3 第 1 条。核心配置：`styleMask = [.borderless, .nonactivatingPanel]` +
`becomesKeyOnlyIfNeeded = true`。

- [ ] **1.1 前台焦点不丢**：在 TextEdit 中连续打字 → 从 Finder 拖一个文件到面板 → 立即在 TextEdit 继续打字，字符应仍进入 TextEdit（面板未抢键盘焦点）
- [ ] **1.2 前台应用不被激活/打断**：拖入瞬间菜单栏仍显示 TextEdit 菜单、Dock 高亮不变、FileTmpShelf 未变成前台 app（accessory 应用无 Dock 图标，以菜单栏归属为准）
- [ ] **1.3 拖入仍正常挂载**：文件成功出现在面板条目上
- [ ] **1.4 反复拖入多次**（连续 5 次）：前台应用焦点始终不丢
- [ ] **1.5 全屏应用上方**（如全屏视频/演示）：唤出面板并拖入，前台全屏应用不被打断，`.fullScreenAuxiliary` 保证面板在全屏之上可见可拖

---

## 2. S4 面板拖放 — 拖入/拖出双向正常

- [ ] **2.1 拖入**：Finder → 面板（文件/文件夹均可），条目出现、名称/来源路径正确
- [ ] **2.2 拖出到 Finder**：从面板条目拖出到「Finder 窗口」→ 出现可放置光标，松开后目标位置出现文件副本
- [ ] **2.3 拖出到桌面**：同 2.2，目标为桌面
- [ ] **2.4 拖出到第三方 App**：拖到文本编辑器附件区 / 浏览器上传框（Safari/Chrome）——不支持属第三方限制，记录即可
- [ ] **2.5 拖出过程中面板保持置顶不消失**（拖拽会话期间面板一直在，无闪烁）
- [ ] **2.6 拖出时面板不动**：从条目区域发起拖拽时面板位置不变（`mouseDownCanMoveWindow = false`）；从面板空白区域拖动时面板仍可移动（不回归）
- [ ] **2.7 不可达条目**：删除源文件后条目变半透明、显示「不可达」，尝试拖出时**不发起拖拽**

## 3. S4 面板拖放 — 多显示器

前置：`isMovableByWindowBackground = true`，按住面板空白处可整体拖动面板。

- [ ] **3.1 跨屏拖放**：把面板拖到副屏 → 从副屏 Finder 拖文件入面板 → 从面板拖出到副屏 Finder 窗口，全程无跳屏/无卡顿
- [ ] **3.2 面板可被拖到任意屏**（利用背景拖动，多显示器移动不受限）
- [ ] **3.3 三屏/排列变更后**：面板位置与显示可见（`canJoinAllSpaces` 全 Space 可见）；重启后位置记忆生效（`panelFrame`）
- [ ] **3.4 显示器拔出/分辨率变化**：存储位置失效时回退主屏右上角，不崩溃

## 4. S4 面板拖放 — 100 条目流畅

- [ ] **4.1 挂载 100 文件**：Finder 中全选 100 个文件一次拖入，条目全部出现，无卡顿（拖入到条目渲染完成耗时对照 S1 的 <1.5s 挂载目标）
- [ ] **4.2 横向滚动**：100 条目下滚动面板货架，帧率正常、无掉帧
- [ ] **4.3 拖出响应**：在 100 条目下连续拖出 5 个条目，每次拖拽会话即时发起、无延迟
- [ ] **4.4 挂载期间面板可交互**：drop 处理 async/await（无主线程阻塞），拖入后滚动/拖出仍即时响应

## 5. S2 拖出真实移动（发布重点）

对应 SPIKE §4.3 通过标准。核心：`NSFilePromiseProvider` + `FileManager.moveItem`。

- [ ] **5.1 同卷 Finder 窗口**：把 1 个文件拖到目标 Finder 窗口（同卷）→ 目标位置出现文件、**源位置文件消失**（真实移动）、货架条目自动移除
- [ ] **5.2 拖到桌面**：同上，目标为桌面，行为一致
- [ ] **5.3 文件夹拖出**：文件夹同样真实移动，源文件夹消失
- [ ] **5.4 拖出取消（Esc）**：拖拽中途取消、未 drop → 文件与货架状态均不变
- [ ] **5.5 移动失败回滚**：目标目录无权限/同名冲突等 → 源文件保持原位（数据零丢失）、货架条目保留，无崩溃
- [ ] **5.6 跨卷行为记录**：拖到外置盘/网络卷，记录最终是复制还是移动（V1 遵循系统复制行为，与 PRD Non-Goals 一致）
- [ ] **5.7 拖出后条目移除**：移动成功后货架条目消失，菜单栏角标数字同步减少

## 6. S3 全局热键

对应 SPIKE §5.3 通过标准。核心：Carbon `RegisterEventHotKey`。

- [ ] **6.1 唤出/隐藏 toggle**：⌥C 唤出面板，再按 ⌥C 隐藏；反复 5 次无异常
- [ ] **6.2 任意前台应用**：在 TextEdit / 浏览器 / 全屏应用等前台状态下 ⌥C 均能唤出
- [ ] **6.3 后台延迟手感**：唤出到面板可见 < 300ms（主观：无卡顿感）
- [ ] **6.4 双入口一致**：菜单栏图标点击唤出与热键唤出行为一致
- [ ] **6.5 冲突检测**：先把 ⌥C 交给另一应用（如系统「显示桌面」等占用场景或临时用其他工具占用）→ 启动 FileTmpShelf，菜单栏标题显示「快捷键冲突」，app 不崩溃

## 7. S1 存储 — 重启恢复 + 失效检测

对应 SPIKE §3.3 通过标准。核心：路径引用 + `fileExists` 检测。

- [ ] **7.1 重启恢复**：挂载若干文件 → 退出并重启 app → 条目全部恢复（名称/来源路径/大小正确）
- [ ] **7.2 失效检测**：重启前删除一个源文件 → 重启后该条目标记「不可达」，无崩溃
- [ ] **7.3 清理失效**：点面板右上角扫把图标 → 不可达条目被移除、可达条目保留（只移除引用）
- [ ] **7.4 iCloud 占位**：挂载 iCloud 中未下载的占位文件 → 条目标记不可达并显示云端图标
- [ ] **7.5 挂载性能**：100 文件一次拖入耗时 < 1.5s，磁盘增量 < 1MB（仅索引）

## 8. 设置窗口验收（Task 1/2 新增）

- [ ] **8.1 打开设置**：菜单栏 →「设置…」或 `⌘,` 打开设置窗口，显示完整表单

- [ ] **8.3 录制校验**：只按纯修饰键被忽略；按无修饰键的普通按键被拒绝并显示提示
