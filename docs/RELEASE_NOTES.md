# FileTmpShelf Release Notes

## v0.1.0 — 初始版本（2026-08-11）

FileTmpShelf 首个可分发版本。常驻菜单栏的「临时文件货架」：按快捷键唤出浮动面板，把文件/文件夹的路径暂时挂上去，拖到系统任意位置即完成真实移动。

### 系统要求

- macOS 13.0 (Ventura) 及以上
- Apple Silicon（M 系列芯片），原生 arm64，不支持 Intel Mac

### 安装

- 下载 `FileTmpShelf-0.1.0.dmg`，拖拽 FileTmpShelf.app 到 Applications
- ⚠️ 本版本为未签名/未公证的分发包，首次启动若被 Gatekeeper 拦截，请右键 →「打开」放行（正式发布版将完成签名与公证）

### 新功能

- **全局快捷键唤出**：默认 `⌥C`，基于 Carbon RegisterEventHotKey，低延迟、无需辅助功能权限；菜单栏图标点击为第二入口
- **路径引用存储（零拷贝挂载）**：拖入文件/文件夹只记录路径引用，不复制文件本体；100 文件毫秒级挂载
- **拖出真实移动**：拖到 Finder 窗口或桌面时源文件真实移动到目标位置，货架条目自动移除；移动失败数据零丢失
- **失效检测**：源文件被删除/移动后条目标记「不可达」（半透明 + 红色标签），可一键清理失效引用
- **iCloud 占位识别**：未下载到本地的 iCloud 占位文件挂载后标记为不可达
- **清空货架**：面板垃圾桶 + 菜单栏「清空货架」双入口，超过阈值弹确认；只移除引用，不删除源文件
- **设置窗口**（菜单栏 →「设置…」/ `⌘,`）：
  - 快捷键录制（点击 → 按下组合键，需至少一个修饰键，立即生效并持久化）
  - 登录时自动启动（SMAppService，正式签名包生效）
  - 面板透明度滑块（50%–100%，默认 90%）
  - 清空确认阈值（3 / 5 / 10 / 始终确认，默认 3）
- **菜单栏角标**：货架有条目时显示数字角标
- **面板位置记忆**：面板位置跨会话记住，显示器变化时回退默认位置

### 已知限制（V1 范围）

- 跨卷拖出遵循系统复制行为，不提供「移动后校验删除」的严格语义（V2）
- iCloud 占位文件需先在 Finder 下载后使用
- 拖到不支持 file promise 的第三方应用时可能无法接收文件
- 仅支持单货架；多货架、拖拽排序、跨卷严格移动列入后续版本

### 资源占用

- 原生 arm64 二进制，常驻内存 < 40MB 目标；应用数据目录仅存轻量索引（<1KB/条目）
