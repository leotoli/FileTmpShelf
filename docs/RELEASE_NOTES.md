# FileTmpShelf Release Notes

## v0.1.1 — 跳转访达 + 细节修复（2026-08-14）

### 新功能

- **⌘↩ 跳转访达**：货架中选中一个文件后按 `⌘↩`，在 Finder 中定位并高亮显示该文件（仅单选；多选 / 无选中时忽略）

### 修复

- **多文件拖出**：修复拖出多个文件时，首文件移动后其余文件显示「不可达」且条目残留的问题
- **⌘↩ 稳定性**：跳转访达改用 Carbon 全局热键（同 ⌥X 机制），修复全屏 app 场景下「只能弹一次访达」/「有时失败」的竞态
- **废弃警告清理**：移除 `NSFilenamesPboardType`（废弃 pboard 类型、非 UTI），拖拽不再刷 `not a valid UTI` 日志警告

### 安装

- 从 [GitHub Releases](https://github.com/leotoli/FileTmpShelf/releases/latest) 下载 `FileTmpShelf-0.1.1.dmg`
- 本版本已 **Developer ID 签名 + 公证**，正常安装无 Gatekeeper 拦截

## v0.1.0 — 首个公开版本（2026-08-13）

FileTmpShelf 首个公开版本。常驻菜单栏的「临时文件货架」：按快捷键唤出浮动面板，把文件/文件夹的路径暂时挂上去，拖到系统任意位置即完成真实移动。

### 系统要求

- macOS 13.0 (Ventura) 及以上
- Apple Silicon（M 系列芯片），原生 arm64，不支持 Intel Mac

### 安装

- 从 [GitHub Releases](https://github.com/leotoli/FileTmpShelf/releases/latest) 下载 `FileTmpShelf-0.1.0.dmg`
- 拖拽 FileTmpShelf.app 到 Applications 即可
- 本版本已 **Developer ID 签名 + 公证**，正常安装无 Gatekeeper 拦截

### 核心功能

- **全局快捷键唤出**：默认 `⌥X`，基于 Carbon RegisterEventHotKey，低延迟、无需辅助功能权限；菜单栏图标点击为第二入口
- **副屏唤醒**：面板出现在鼠标当前所在屏幕的对应位置，多屏工作不跨屏找
- **路径引用存储（零拷贝挂载）**：拖入文件/文件夹只记录路径引用，不复制文件本体；100 文件毫秒级挂载
- **拖出真实移动**：拖到 Finder 窗口或桌面时源文件真实移动到目标位置，货架条目自动移除；跨卷移动带完整性校验（复制→校验→删源），数据零丢失
- **多货架**：按项目分组多个货架，新建/重命名/删除/切换，条目相互隔离
- **多选批量移动**：⌘ 点击多选 / ⇧ 区间选择，批量拖出多个文件
- **文件夹支持**：文件夹与文件同等对待（蓝色文件夹图标区分），拖出即移动整目录
- **关闭按键**：Esc 或面板左上角 ⓧ 关闭面板；面板底部多选快捷键提示
- **失效检测**：源文件被删除/移动后条目标记「不可达」（半透明 + 红色标签），可一键清理失效引用
- **iCloud 占位识别**：未下载到本地的 iCloud 占位文件挂载后标记为不可达
- **清空货架**：面板垃圾桶（清空当前）+ 设置页「清除所有货架」（清空全部）；只移除引用，不删除源文件
- **手动更新**：设置页「检查更新」+ 启动时菜单栏静默提醒新版本
- **设置窗口**（菜单栏 →「设置…」/ `⌘,`）：
  - 快捷键录制（点击 → 按下组合键，需至少一个修饰键，立即生效并持久化）
  - 登录时自动启动（SMAppService，签名包生效）
  - 面板透明度滑块（50%–100%，默认 90%）
  - 清空确认阈值（3 / 5 / 10 / 始终确认，默认 3）
  - 清除所有货架
  - 关于（版本号 / GitHub 仓库 / 检查更新）
- **菜单栏角标**：货架有条目时显示数字角标
- **面板位置记忆**：相对屏幕锚点记忆，跨屏幕/分辨率一致

### 已知限制

- iCloud 占位文件需先在 Finder 下载后使用
- 拖到不支持 file promise 的第三方应用时可能无法接收文件
- 仅支持 Apple Silicon（M 系列），不支持 Intel Mac
- 手动更新（不自动后台更新），需在设置页或菜单栏手动检查

### 资源占用

- 原生 arm64 二进制，常驻物理内存约 50MB；应用数据目录仅存轻量索引（<1KB/条目）
