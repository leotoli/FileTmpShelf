# FileTmpShelf FAQ（常见问题）

面向最终用户与客服/支持团队。所有说明与 v0.1.1 实际行为一致。

---

## 1. 跨卷移动说明

**问题：把货架条目拖到外置盘 / 网络卷，是移动还是复制？**

- **同卷**（如本地磁盘内部，包括不同文件夹之间）：拖出执行**真实移动**——源文件瞬时移动到目标位置，源位置不再保留，货架条目自动移除。
- **跨卷**（如本地盘 → 外置盘、SMB 网络卷）：同样执行**真实移动**，采用「复制 → 校验完整性 → 删除源」的三阶段流程：
  - 复制到目标卷后，校验目标完整（文件比大小、目录比递归条目数）
  - 校验通过才删除源文件，确保数据零丢失
  - 复制失败 / 校验失败 / 删源失败均**保留源文件**，不会出现「源已删但目标缺失」的中间态
- 跨卷移动本质是拷贝数据，耗时与文件大小相关（同卷是瞬时重命名）。

## 2. 失效条目说明（「不可达」）

**问题：为什么有的条目变半透明并显示红色「不可达」？**

- 货架只存路径引用。当源文件被外部**删除或移动**后，应用检测到该路径不再存在，条目即标记为「不可达」：
  - 条目变半透明、显示红色「不可达」标签
  - 不可达条目**无法拖出**（不发起拖拽）
  - 应用重启时会重新检测并标记失效条目，不会崩溃
- **清理**：点面板右上角的**扫把图标**（「清理失效」）一键移除全部失效引用，只移除引用、不影响任何文件。

## 3. iCloud 占位文件提示

**问题：从 iCloud 拖入的文件为什么是「不可达」？**

- 挂载时应用会检测文件的 iCloud 状态。当文件**尚未下载到本地**（仅有 `.icloud` 占位存根）时，条目会被标记为「不可达」——因为本地只有占位，无法真实移动该文件（这是有意设计，避免误移走空壳存根）。
- 处理方式：先在 Finder 中让文件**下载完成**，再重新拖入货架使用。
- 已完整下载的 iCloud 文件可正常挂载与拖出（等同本地文件）。

## 4. 快捷键冲突处理

**问题：⌥X 被其他应用占用了怎么办？**

- 全局快捷键基于 Carbon RegisterEventHotKey 注册。若 ⌥X 已被本机其他应用占用，注册会失败，此时：
  - 菜单栏第一个菜单项标题会显示「快捷键冲突」
  - 打开「设置」→ 快捷键，点击后**录制一个新组合键**（需至少包含一个 ⌘ / ⌥ / ⌃ / ⇧ 修饰键），新键立即生效并持久化
- 录制时禁止纯修饰键（只按 ⌘/⌥/⌃/⇧ 不构成组合键）；无修饰键的按键会被拒绝并提示。
- 说明：应用能可靠检测「注册失败 = 被占用」，但不提供全系统占用清单（那需要「辅助功能」权限）。

## 5. 清空只移除引用，不删除源文件

**问题：点「清空货架」会不会把我的文件删掉？**

- **不会。** 货架存的是路径引用，清空只把条目从货架移除，源文件始终停留在原位置，原封不动。
- 清空入口：
  - 面板右上角**垃圾桶按钮**：清空当前货架
  - 设置页「危险操作」→「清除所有货架」：清空全部货架（保留货架本身），条目数超过阈值时弹确认
- 同理，「清理失效」也只移除不可达的引用，同样不会删除任何文件。

## 6. 如何卸载

1. 退出 FileTmpShelf（菜单栏 →「退出」）
2. 删除应用：把 `/Applications/FileTmpShelf.app` 拖入废纸篓
3. （可选）删除残留数据：
   - 货架索引：`~/Library/Application Support/FileTmpShelf/`（含 `shelves.json` 与各 `shelf-<id>.json`）
   - 设置与面板位置：`defaults delete com.filetmpshelf.app`

## 7. 如何重置设置

```bash
defaults delete com.filetmpshelf.app   # 重置全部设置（含快捷键、透明度、阈值、面板位置）
```

然后重新启动应用即可恢复到默认值（快捷键回到 ⌥X、透明度 90%、阈值 3、面板回到默认锚点）。

## 8. 其他常见问题

### 8.1 拖到第三方 App（浏览器上传框等）不生效？
拖出的优先目标是 **Finder 窗口与桌面**。已针对常见应用（微信、iTerm2 等）做了兼容处理（拖出时附带真实文件路径），大多数应用可正常接收。拖到不支持 file promise 机制的应用时可能仍无法接收，这属于第三方限制。

### 8.2 「登录时自动启动」开了却不生效？
开机启动使用系统登录项（SMAppService），**需要签名后的正式安装包**才生效。v0.1.1 已签名 + 公证，正常安装后功能即可生效。

### 8.3 为什么菜单栏没有图标 / 没有 Dock 图标？
- 菜单栏托盘图标（`tray.full`）在应用启动后常驻，图标旁会显示条目数字角标（条目 > 0 时）。
- 应用是**菜单栏附属（accessory）应用，无 Dock 图标**，这是正常设计。
- 启动时若发现新版本，菜单栏会插入「🆕 发现新版本」菜单项（静默提醒，不弹窗）。

### 8.4 应用重启后货架还在吗？
在。货架索引持久化在 `~/Library/Application Support/FileTmpShelf/`（`shelves.json` 货架列表 + `shelf-<id>.json` 各货架条目），重启后自动恢复；源文件已不可达的条目会标记「不可达」。

### 8.5 dmg 首次打开提示无法验证开发者？
v0.1.1 已**签名 + 公证**，正常下载安装**无 Gatekeeper 拦截**。若仍提示（如网络环境无法联网验证公证），右键应用 →「打开」可放行。

### 8.6 大文件挂载会很慢吗？
不会。挂载只是记录路径引用（不复制文件），100 个文件实测约毫秒级；移动文件只在**拖出**时发生（跨卷移动因需拷贝数据，耗时与文件大小相关）。

### 8.7 支持文件夹吗？
支持。文件与文件夹同等对待：拖入挂载（零拷贝）、拖出真实移动整目录（跨卷校验递归条目数）。文件夹在货架上显示为蓝色文件夹图标，与文件区分。

### 8.8 如何多选批量移动？
- **⌘ 点击**切换选中单个条目，**⇧ 点击**区间选择
- 选中多个后，拖拽任一选中条目即批量移动整组
- 面板底部有「⌘ 点击多选 · ⇧ 区间选择」提示，选中时显示「已选 N 个」

### 8.9 如何管理多个货架？
点面板左上角「货架管理」（齿轮图标）→ 切换货架（点货架名）/ 新建（底部输入框）/ 重命名（铅笔图标）/ 删除（垃圾桶图标）。每个货架条目相互隔离。

### 8.10 如何检查更新？
- 手动：设置页 →「关于」→「检查更新」
- 自动：应用启动时静默检查（每天最多 1 次），发现新版本菜单栏插入「🆕 发现新版本」项，点击打开下载页面
