# FileTmpShelf

常驻菜单栏的「临时文件货架」——按快捷键唤出浮动面板，把任意文件/文件夹的路径暂时挂上去，再拖到系统任意位置，文件就真正到位。

与拷贝型工具（Yoink / Dropover）不同，FileTmpShelf **只存路径引用、不复制文件本体**：20GB 的视频也能瞬间挂载；拖到 Finder 或桌面时执行**真实移动**，源位置不再保留。

> 当前版本：**v0.1.0**（详见 [docs/RELEASE_NOTES.md](docs/RELEASE_NOTES.md)）

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 快捷键唤出 | 默认 **⌥X** 全局唤出/隐藏面板（可在设置中自定义），也可点菜单栏图标唤出 |
| 副屏唤醒 | 面板出现在**鼠标当前所在屏幕**的对应位置，多屏工作不跨屏找 |
| 拖入挂载 | 把文件/文件夹从任意位置拖到面板，**零拷贝**：只记录路径引用，秒级完成 |
| 拖出移动 | 拖到 Finder 窗口或桌面 → 源文件**真实移动**到目标位置，货架条目自动移除；跨卷移动带完整性校验（复制→校验→删源） |
| 多货架 | 按项目分组多个货架，新建/重命名/删除/切换，条目相互隔离 |
| 多选批量 | **⌘ 点击多选 / ⇧ 区间选择**，批量拖出多个文件 |
| 关闭按键 | **Esc** 或面板左上角 **ⓧ** 关闭面板 |
| 清空货架 | 一键移除全部引用；超过阈值时弹确认（默认 3 条） |
| 清理失效 | 源文件已删除/移动的条目标记「不可达」，一键清理失效引用 |
| 手动更新 | 设置页「检查更新」，启动时菜单栏静默提醒新版本 |
| 设置 | 自定义快捷键、开机启动、面板透明度、清空确认阈值、清除所有货架、关于 |

## 系统要求

- **macOS 13.0 (Ventura) 或更高**
- **仅 Apple Silicon（M 系列芯片）**：原生 arm64 二进制，不支持 Intel Mac
- 无沙盒限制，不依赖「辅助功能」权限（全局快捷键基于 Carbon RegisterEventHotKey）

## 安装

1. 从 [GitHub Releases](https://github.com/leotoli/FileTmpShelf/releases/latest) 下载 `FileTmpShelf-0.1.0.dmg`
2. 双击挂载 dmg，将 **FileTmpShelf.app 拖入 Applications 文件夹**
3. 从启动台或 Applications 打开 FileTmpShelf，菜单栏出现托盘图标即运行成功

## 使用说明

1. **唤出/隐藏面板**：按 `⌥X`，或点击菜单栏托盘图标。面板出现在鼠标所在屏幕，可按住面板空白处拖动换位置（位置会被记住）
2. **挂载文件/文件夹**：从 Finder 等位置把文件或文件夹拖到面板上，条目显示图标（文件 `doc` / 文件夹 `folder` / iCloud 占位 `cloud`）、名称、来源路径
3. **归位文件**：把面板上的条目拖到 Finder 窗口或桌面 → 源文件被真实移动到目标位置，条目自动从货架移除
4. **多选批量操作**：`⌘` 点击切换选中、`⇧` 点击区间选择，然后拖拽任一选中条目即批量移动整组
5. **关闭面板**：按 `Esc` 或点面板左上角 `ⓧ`
6. **货架管理**：点面板左上角「货架管理」→ 切换货架（点货架名）/ 新建（底部输入框）/ 重命名（铅笔图标）/ 删除（垃圾桶图标）
7. **清空货架**：点面板垃圾桶，或菜单栏 →「清空货架」（条目数超过设置阈值时弹确认）
8. **清理失效**：源文件被删除后条目变半透明并显示「不可达」；点扫把图标一键移除失效引用
9. **检查更新**：设置页 →「关于」→「检查更新」，或菜单栏出现「🆕 发现新版本」时点击
10. **退出**：菜单栏 →「退出」

### 快捷键

| 快捷键 | 作用 |
|--------|------|
| `⌥X` | 唤出 / 隐藏货架面板（默认，可在设置中修改） |
| `Esc` | 关闭面板 |
| `⌘ 点击` | 多选条目（切换选中） |
| `⇧ 点击` | 区间选择条目 |
| `⌘,` | 打开设置 |
| `⌘Q` | 退出应用 |

### 设置项（菜单栏 →「设置…」/ `⌘,`）

- **快捷键**：点击当前快捷键 → 按下新组合键（需至少含一个 ⌘ / ⌥ / ⌃ / ⇧ 修饰键），立即生效并持久化；发生冲突时菜单栏标题显示「快捷键冲突」
- **登录时自动启动**：使用系统登录项（SMAppService），正式签名包中生效
- **面板透明度**：滑块 50%–100%，实时生效（默认 90%）
- **清空确认阈值**：3 / 5 / 10 条以内直接清空，或始终确认（默认 3）
- **清除所有货架**：清空全部货架的条目（保留货架本身），仅移除引用不删源文件
- **关于**：版本号、GitHub 仓库链接、检查更新

### 数据存储

- 货架条目索引：`~/Library/Application Support/FileTmpShelf/` 下 `shelves.json`（货架列表）+ `shelf-<id>.json`（各货架条目），仅路径引用 + 元数据，<1KB/条目，不复制文件
- 设置：UserDefaults（`com.filetmpshelf.app`）
- 面板位置：UserDefaults 锚点+偏移（`panelAnchor` / `panelOffset`），跨屏幕/分辨率一致

## 已知限制

- **iCloud 占位文件**（未下载到本地）挂载后标记为不可达，需先在 Finder 中下载后再使用
- **第三方 App**：优先目标是 Finder 与桌面；拖到不支持 file promise 的应用时可能无法接收
- **手动更新**：不自动后台更新，需在设置页或菜单栏手动检查并下载
- 仅 Apple Silicon（M 系列），不支持 Intel Mac

## 开发

```bash
cd FileTmpShelf && xcodegen generate   # 项目变更后必跑
xcodebuild -project FileTmpShelf.xcodeproj -scheme FileTmpShelf -destination "platform=macOS" build
cd FileTmpShelf && xcodebuild test     # 全量测试（HotKeyManagerTests 会注册 ⌥X，避免与其他 xcodebuild 进程并发）
```

发布打包与公证流程见 [docs/RELEASE.md](docs/RELEASE.md)。
